# Dataset

## Sample Governance Dataset

The `sample_governance_data.csv` file contains simulated governance/service records created for academic prototype development.

## Purpose

The dataset is intended to demonstrate how governance/service data could be structured for:

- Data processing
- Exploratory analysis
- KPI generation
- Anomaly detection
- Administrative decision support

## Dataset Fields

| Field | Description |
|---|---|
| record_id | Unique identifier for each sample record |
| department | Department associated with the service |
| service_type | Type of governance/service activity |
| requests_received | Number of requests received |
| requests_completed | Number of requests completed |
| pending_requests | Number of requests still pending |
| response_time_hours | Average response time in hours |
| status | Sample operational status |

## Data Classification

**Data Type:** Simulated / Synthetic

**Purpose:** Academic prototype development

**Real Government Data:** Not used

## Important Note

The dataset does not represent actual government records, citizens, departments or transactions.

It is created only to demonstrate the proposed data-processing and analytics workflow.
