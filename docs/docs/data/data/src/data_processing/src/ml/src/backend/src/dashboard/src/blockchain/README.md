# Blockchain / Audit Layer

This module will contain the proposed audit mechanism for selected administrative records requiring tamper-evident traceability.

## Planned Purpose

- Record traceability
- Auditability
- Integrity of selected records
- Controlled access

## Proposed Approach

A permissioned blockchain prototype or smart-contract-based audit layer may be evaluated for selected records.

## Important

The blockchain layer is not intended to store all application data.

## Current Status

Audit/blockchain module planned for prototype development.
